# Weather Mood 

A cute and responsive weather application that displays real-time weather information using the OpenWeather API.

## Features

- Search weather by city name
- Display current temperature
- Show weather conditions
- Display humidity
- Display wind speed
- Weather-based emojis and messages
- Responsive design
- Enter key support for searching

## Technologies Used

- HTML
- CSS
- JavaScript
- OpenWeather API

## What I Learned

- Working with APIs
- Using JavaScript `fetch()`
- Handling asynchronous functions
- Reading JSON data
- Updating webpage content dynamically
- Handling errors
- Creating a responsive user interface
